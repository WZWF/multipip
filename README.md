# 多窗播放 Multi-PiP (v0.9)

一个面向 Chrome / Edge / Brave（Chromium 116+）的视频多窗与画中画增强扩展：支持将任意网页（B 站、YouTube、腾讯视频、爱奇艺、优酷、各类网课/公开课、直播等）的视频弹出为置顶窗口，提供**跨标签页多视频同窗合并（多视频坞）**与**无限多开的真·无边框置顶窗**。

---

## 核心特性

1. **全网通用的高画质本地 WebRTC 直推（Local WebRTC Loopback HQ）**
   - 只要网页里有 `<video>` 元素，即可通过浏览器原生满帧捕获 + 本机内存级 WebRTC 回环通道（`iceServers: []` + `127.0.0.1` 直连，零外网请求、免疫防火墙/代理虚拟网卡 mDNS 拦截、延迟 < 30ms）将视频推送至跨标签页置顶坞或原生无边框窗。
   - **蓝光级原画质直通**：自动注入高码率 SDP（最高 `35Mbps`）并锁定 `1:1` 原始分辨率（`maintain-resolution`），60fps 高清画面零缩水；原页面保留原生音轨播放（无二次重编码失真、无双重声音），小窗控件实时反向控制原视频。

2. **三种置顶模式 + 自动降级兜底**

   | 模式 | 窗口形态 | 置顶 | 数量限制 | 适用场景 |
   | :--- | :--- | :---: | :---: | :--- |
   | **原生小窗**（`dock`） | 多视频置顶坞：无边框置顶窗，内置 5 种布局与独立卡片控件 | 是 | 全局 1 窗（可合并多个同页/跨标签页视频） | 多路比赛/直播同屏、边看网课边看资料 |
   | **原生画中画**（`native`） | 浏览器自带极简画中画窗 | 是 | 全局 1 窗 | 单视频极简置顶观看 |
   | **无边框窗**（`companion`） | 原生伴侣程序：无标题栏、无地址栏、支持一键全屏平铺与外挂字幕 | 是 | **无限制（可无限多开）** | 多窗口自由摆放、跨屏排布、挂载本地字幕 |
   | **独立窗口**（`window`） | 浏览器 `window.open` 弹窗（当页面不支持 PiP 时自动兜底） | 否 | 不限（带地址栏） | HTTP 页面或受限环境自动降级 |

3. **多视频坞（原生小窗）交互**
   - **五种布局一键切换**：堆叠（按比例）/ 宫格 / 大+左 / 大+右 / **自由布局**（任意拖拽位置与无级缩放大小，按窗口比例记忆位置）。
   - **窗口与卡片全屏**：支持整个坞窗口一键全屏或小/中/大三档缩放；支持单张视频卡片在坞内全屏独占（其余卡片自动暂停，退出后恢复）。
   - **完整控制条**：悬停卡片浮现播放/暂停、进度条、音量、**倍速循环（0.5x ~ 2.0x）**、全屏独占与召回按钮。

4. **无边框原生伴侣窗（免 Python、零配置修改）**
   - **一键多窗排版**：面板内置「均分平铺」「左右对分」「上分下独」「左大右辅」四种全屏自动排布。
   - **本地外挂字幕**：支持点击挂载或直接将 `.srt` / `.vtt` 字幕文件拖入无边框窗口。
   - **快捷键与极速倍速**：支持 `空格` 播放/暂停、`←/→` 快退/快进 5 秒、**长按鼠标右键（或长按 `→` 右方向键）触发 2.5x 倍速冲刺（松开恢复原倍速）**，以及随时切换窗口置顶状态。

5. **克制无感、零打扰的页面交互**
   - **无视频页 100% 隐形**：仅在检测到有效视频的顶层主页面显示右侧贴边微露胶囊（自动屏蔽无视频普通网页、内嵌 `iframe` 及小弹窗），移入自动滑出，并支持点击 `×` 一键隐藏。
   - **右上角角落精准唤醒**：平时鼠标在视频中央观看、暂停或拖进度条时画面纯净无遮挡；仅将鼠标移至**视频画面右上角小区域**时才会柔和浮现「独立播放」按钮，移开即刻消失（全屏及小缩略图自动免打扰）。

## 快速安装（零配置修改，即装即用）

本项目已内置固定扩展公钥与相对路径宿主清单，**克隆或下载解压到任意电脑、任意盘符均无需修改任何配置文件**。

### 第一步：获取项目
- **方式 A（Git 克隆）**：
  ```bash
  git clone git@github.com:WZWF/multipip.git
  # 或者使用 HTTPS:
  git clone https://github.com/WZWF/multipip.git
  ```
- **方式 B（压缩包下载）**：
  在 [GitHub 仓库页面](https://github.com/WZWF/multipip) 点击右上角绿色 `Code` -> `Download ZIP`，解压到本地任意固定目录（注意：安装后请勿移动该文件夹）。

### 第二步：在浏览器中加载扩展
1. 打开 Chrome 访问 `chrome://extensions/`（Edge 访问 `edge://extensions/`）。
2. 开启右上角的 **「开发者模式」**。
3. 点击左上角 **「加载已解压的扩展程序」**，选择解压后的项目根目录（包含 `manifest.json` 的文件夹），或直接将该文件夹拖入扩展管理页面。

### 第三步：（可选）一键开启「无边框原生窗」
> 如果只需要使用「原生小窗（多视频坞）」和「原生画中画」，跳过此步即可。

1. 进入项目下的 `companion` 文件夹，**双击运行 `register_host.bat`**（无需安装 Python，无需管理员权限，无需手动输入扩展 ID）。
2. 回到浏览器扩展管理页（`chrome://extensions/`），点击本扩展卡片上的 **刷新** 图标即可生效。
3. *（如需卸载伴侣注册表项，双击运行 `companion/unregister_host.bat` 即可。）*

## 使用指南

1. 打开任意包含视频的网页。
2. **弹出视频**：
   - 将鼠标移至**视频画面右上角角落**，点击浮现的 **「独立播放」** 按钮（平时在视频中间移动鼠标不遮挡画面）；
   - 或将鼠标移至网页右侧边缘滑出 **「🎬 多窗播放」** 胶囊按钮（仅含视频的主页面显示），在面板中选择模式并点击对应视频的 **「弹出」**。
3. **多视频合并 / 排版**：
   - **原生小窗模式**：在标签页 A 弹出第一个视频后，切换到标签页 B 再次点击弹出，视频 B 会自动合并进同一个置顶小窗中。
   - **无边框窗模式**：切换到「无边框窗」后可连续弹出多个独立置顶窗口，点击右下角面板中的 **「多窗排版」** 即可一键平铺到屏幕。
4. **全局倍速快捷键**：按 `Alt + Shift + S` 可快速循环切换当前活动视频的播放倍速（`0.5x` ~ `2.0x`）。
5. **召回视频**：按 `Esc`、点击小窗右上角 `×`、点击原网页上的占位提示条，或在右下角面板中点击「召回」，即可将视频无缝放回原网页。

## 目录结构

```text
multipip/
├── manifest.json                 # MV3 扩展清单（含固定公钥 key、nativeMessaging、快捷键 Alt+Shift+S）
├── content.js                    # 核心逻辑：多视频坞(5种布局/自由缩放) / 本地 WebRTC 跨标签推流 / 面板与排版
├── background.js                 # Service Worker：坞归属管理 + WebRTC 信令/控制中继 + 伴侣进程桥接
├── popup.html                    # 浏览器工具栏图标弹窗说明
├── icons/                        # 16 / 48 / 128 PNG 扩展图标
└── companion/                    # 无边框原生窗伴侣（免 Python、零配置修改）
    ├── com.multipip.host.json    # 便携式原生消息宿主清单（相对路径 + 固定扩展 ID）
    ├── register_host.bat         # 双击一键写入当前用户注册表（支持 Chrome / Edge / Brave / Chromium）
    ├── unregister_host.bat       # 双击一键清理注册表项
    └── dist/multipip_host/       # 独立可执行程序目录（基于系统 WebView2）
```

## 常见问题与限制

- **为什么有的视频（如 Netflix）提示无法捕获画面流？**  
  受硬件级 DRM（Widevine L1 等）保护的加密流媒体在浏览器底层禁止 `captureStream()`，此时请改用浏览器自带的「原生画中画」模式。
- **跨标签页合并或使用无边框窗时，原网页可以关掉吗？**  
  不能关闭源标签页（可以切换到后台或其他标签页）。画面流与音频由源标签页实时解码提供，扩展已自动阻止后台标签页被浏览器休眠暂停。
- **移动了项目文件夹位置后怎么办？**  
  如果移动了项目目录，请在浏览器 `chrome://extensions/` 中重新加载新路径，并重新双击一次 `companion/register_host.bat`。
